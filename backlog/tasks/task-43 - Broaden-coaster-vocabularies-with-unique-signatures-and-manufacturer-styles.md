## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Owner direction (2026-11-03): fill in realistic track for each model. Examples: Intamin-style coasters support chain lifts; lifts have variable speed; lifts can go up to 60 degrees. What makes a model unique: its most distinctive or extreme elements stay unique, and variations follow the parent type's style. Elements unusual for a type, such as a loop on a wooden coaster, are allowed but marked unusual and will cost more once costs exist. Aesthetics differ per manufacturer: RMC-inspired models use wooden supports, Intamin-inspired models Intamin-style steel supports, GCI-inspired models dense timber.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 All models share a broad common vocabulary (straights, slopes and transitions, turns, banks, helixes, airtime hills) and support chain lifts unless the real type never uses them
- [ ] #2 Lifts have a per-section speed setting and steep lift pieces up to 60 degrees where plausible
- [ ] #3 Each model keeps a documented set of signature elements, including more extreme versions unique to it
- [ ] #4 Pieces unusual for a model are marked as such in model data and in the builder, ready for a cost multiplier
- [ ] #5 Supports and track are drawn in a manufacturer-specific style for each model
